# ✦ VEXA AI — Architecture & LLM Research Report

Overview of models, voice orchestration, and system integration strategies for **VEXA AI**.

---

## 1. Core Reasoning & Intelligence

- **NVIDIA NIM (Active)**: Meta Llama 3.1 405B / Llama 4 via NVIDIA API Catalog.
- **Anthropic Claude (Active)**: Multi-step logic and coding.
- **DeepSeek R1**: Advanced reasoning, logic, and code synthesis.

---

## 2. Voice & Multimodal Extensions

- **ElevenLabs**: Expressive text-to-speech synthesis.
- **Cartesia**: Ultra-low latency voice rendering.
- **Deepgram**: Real-time speech-to-text recognition.

---

## 3. Supported Architecture Pipelines

- **Fast Interface**: Deepgram STT + Llama 3.1 405B + Cartesia TTS
- **Reasoning Node**: Deepgram STT + Claude 3.5/4 + ElevenLabs TTS
