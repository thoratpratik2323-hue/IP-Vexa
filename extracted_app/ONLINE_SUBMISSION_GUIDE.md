# 🌐 Online Bootcamp Submission & Testing Guide for Judges

How to package, record, and submit **VEXA AI** for your online AI bootcamp.

## ❓ How Will Judges Test Your AI Project Online?

Judges at online AI bootcamps evaluate projects in **3 Steps**:

### Step 1: Video Demo (Loom / YouTube Link) — *Most Important!*
Judges watch a 2 to 3-minute video showing the app in action.
- Record your screen using **Loom** (free at loom.com) or **OBS**.
- Follow the exact 3-minute script in [WINNING_BOOTCAMP_STRATEGY.md](file:///home/pratik_pt1908/Downloads/IP_VEXA_PORTABLE_FOR_FRIEND/extracted_app/WINNING_BOOTCAMP_STRATEGY.md).

### Step 2: GitHub Repository Link
Submit your project GitHub link.
- Upload the `vexa-ai-desktop` project folder to GitHub.
- Ensure `README.md`, `BOOTCAMP_PITCH.md`, and `SETUP_GUIDE.md` are present.

### Step 3: Zero-Setup Judge Testing ("1-Click Demo Mode")
Do judges need their own API keys to test your app? **NO!**
- We added a **`⚡ 1-Click Demo Mode (For Judges)`** button on the launch screen.
- When judges launch VEXA AI, they can simply click **`1-Click Demo Mode`** and immediately test folder scanning (`/scan`), voice mode, system commands (`/cpu`, `/ip`), and chat without typing any API keys!
